Se corrigió la pérdida de cambios en productos: editar un precio, un stock o una categoría ya no se revierte al rato ni al día siguiente.

- Un cambio hecho mientras el sistema sincronizaba ya no se descarta.
- Los códigos de barras duplicados dejan de borrarse solos: ahora se reportan en Ajustes → Sincronización para que decidas vos.
- Las subcategorías de un producto ya no se pierden al sincronizar.
- Las imágenes de productos dejan de llenar el sistema de errores, y las que quedaron rotas se vuelven a descargar solas.
- Actualizaciones: ahora se ve qué cambia antes de instalar y se puede posponer.
- Al agregar/Editar un producto se puede saltar entre secciones.
